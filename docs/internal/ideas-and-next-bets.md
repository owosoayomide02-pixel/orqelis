# Ideas and next bets

Orqelis V1 should stay an endpoint security product that tells the truth.

## Done in this slice

- TOTP MFA (enroll, login challenge, disable)
- OS-aware Gatekeeper / Linux firewall detections
- Founder console: agent versions, system incidents, AI cost
- Weekly report also sends a digest email (log or SMTP)
- Agent HTTP retries
- V1/V2 completion matrix: `docs/internal/completion-matrix.md`

## Cannot finish here

- Signed installers (need Apple/Microsoft signing certs)
- Live billing (need a payment provider account)
- V3 ecosystem / V4 autonomous OS (Security Graph, isolate, marketplace)

## Do not do yet

- Security Graph / attack-path engine / digital twin
- Marketplace
- Autonomous isolate, kill-process, or credential revoke
- Claiming SOC 2, ISO 27001, or similar certifications
