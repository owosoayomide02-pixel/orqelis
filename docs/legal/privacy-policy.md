## Scope

This policy applies to the Orqelis website, customer accounts, dashboards, Windows endpoint agent, APIs, and related services.

## Information we collect

- Account: name, email, organization, role, authentication data
- Billing: processed by a future payment provider; card numbers are not stored by Orqelis in V1
- Device / telemetry: device identifier, hostname, OS, agent version, process metadata, selected Windows security events, service state, selected network connection metadata, security-control status, agent health
- Audit records of security-relevant actions

The agent does not collect personal documents, clipboard contents, or keystrokes.

## AI processing

Some features send minimized, redacted security context to an AI provider through the Orqelis AI gateway. Provider keys are never exposed to browsers or agents. AI output assists authorized users and is not a definitive security determination.
